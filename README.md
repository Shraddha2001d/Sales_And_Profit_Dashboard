# Sales_And_Profit_Dashboard
Excel Dashboard Project | Sales &amp; Profit Analysis | Pivot Tables | Pivot Charts | Slicers | Data Visualization
## 📌 Overview
This project is an interactive Sales and Profit Dashboard created using Microsoft Excel. It provides insights into sales performance, profit trends, customer count, category-wise sales, state-wise sales, and top-performing customers.
## ❓ Problem Statement
Businesses often struggle to track sales performance and profitability across multiple dimensions such as product categories, customers, regions, and time periods. The objective of this project is to create a centralized dashboard that provides actionable insights for better decision-making and performance monitoring.
## 🗂️ Dataset
The dataset contains transactional sales data with the following information:
- Order Date
- Sales Amount
- Profit Amount
- Product Category
- Customer Name
- State/Region
- Year and Month
#### The data was cleaned and structured before being used for dashboard creation.
## 🛠️ Tools and Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Dashboard Design Techniques
## ⚙️ Method
1. Collected and cleaned the sales dataset.
2. Created Pivot Tables for data summarization.
3. Designed KPI cards to display Total Sales and Total Profit.
4. Built Pivot Charts for trend and category analysis.
5. Added Slicers for dynamic filtering.
6. Developed an interactive dashboard layout with consistent formatting and visual elements.
7. Validated calculations and insights for accuracy.
## 📊 Dashboard Description
#### KPI Cards
- Total Sales
- Total Profit
#### Interactive Filters
- Year
- Category
- Month
#### Visualizations
- Profit by Year
- Sales by Category
- Customer Count Analysis
- Sales by State (Map)
- Top 5 Customers by Profit
- Monthly Sales Trend
#### The dashboard updates dynamically based on user selections, enabling quick and effective analysis.

## 💡 Key Insights
- Achieved ₹19.28 Lakhs in total sales and ₹2.48 Lakhs in total profit.
- Technology category generated the highest profit among all categories.
- Phones and Chairs were the top-performing product sub-categories by sales.
- Customer count showed steady growth from 2021 to 2023, indicating increased customer engagement.
- March, November, and December recorded the highest sales, highlighting strong seasonal demand.
- State-wise analysis helped identify high-performing regions and potential growth opportunities.
